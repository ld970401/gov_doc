# GovDoc Agent 服务项目文档

## 1. 项目概述

GovDoc Agent 是一个基于 FastAPI 构建的智能文档代理服务，提供对话管理、工作区文档管理、用户配置和 AI 模型集成等功能。

### 1.1 技术栈

- **后端框架**: FastAPI (Python)
- **数据库**: MySQL (默认) / SQLite (可选)
- **ORM**: SQLAlchemy 2.0
- **数据验证**: Pydantic V2
- **AI 模型**: 支持 OpenAI 兼容接口（Qwen3、MiniMax 等）
- **实时通信**: SSE (Server-Sent Events)

### 1.2 项目结构

```
govdoc-agent/
├── app/                      # 应用核心代码
│   ├── main.py              # FastAPI 应用入口
│   ├── config.py            # 配置管理
│   ├── db.py                # 数据库连接
│   ├── models.py            # SQLAlchemy 数据模型
│   ├── schemas.py           # Pydantic 请求/响应模型
│   ├── auth.py              # 鉴权模块
│   ├── runtime.py           # 运行时逻辑
│   └── routes/              # 路由模块
│       ├── me.py            # 用户信息与健康检查
│       ├── conversations.py # 会话管理
│       ├── workspace.py     # 工作区管理
│       ├── settings.py      # 用户设置
│       ├── skills.py        # 技能管理
│       └── models.py        # 模型管理
├── config/
│   └── model.json           # LLM 模型配置
├── .env                     # 环境变量配置
└── .env.example             # 环境变量示例
```

## 3. API 接口定义

### 3.1 统一响应格式

所有接口均使用统一的 JSON 响应格式:

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 响应代码，0 表示成功 |
| message | String | 响应消息 |
| data | Any | 响应数据 |

### 3.2 鉴权方式

- **Header 鉴权**: `X-Legacy-User-Id`, `X-Legacy-Account`, `X-Legacy-Name`
- **Cookie 鉴权**: 通过旧系统 Cookie 验证
- **开发 Mock**: `ENABLE_DEV_AUTH_MOCK=true` 时启用

### 3.3 接口清单

#### 3.3.1 健康检查与用户信息 (`/api/agentloop`)

| GET | `/api/agentloop/models` | 获取可用模型列表 | 是 |

## 5. 核心业务流程

### 5.1 会话运行流程

```
用户发送消息
    ↓
创建/选择会话
    ↓
准备运行上下文 (prepare_run_conversation)
    ↓
创建 V4ConversationRun 记录
    ↓
后台执行 Agent 任务 (execute_prepared_run)
    ↓
实时推送 SSE 事件流
    ↓
任务完成/失败/等待用户
    ↓
发送 [DONE] 事件
```

### 5.2 文档版本管理

```
创建/上传文档
    ↓
创建 V4WorkspaceNode 记录
    ↓
写入文件到存储系统
    ↓
创建 V4WorkspaceVersion (version_no=1)
    ↓
每次更新文档
    ↓
version_no + 1
    ↓
创建新版本记录
    ↓
保留所有历史版本
```

### 5.3 用户记忆管理

```
用户首次登录
    ↓
创建 V4UserProfile 记录
    ↓
初始化记忆文件 (identify.md, memory.md)
    ↓
用户更新记忆
    ↓
更新数据库 JSON 字段
    ↓
写入 Markdown 文件
    ↓
同步记忆投影
```

**role** (消息):
- `user`: 用户
- `assistant`: 助手
- `system`: 系统

**status** (运行):
- `created`: 已创建
- `running`: 运行中
- `completed`: 已完成
- `failed`: 失败
- `waiting_user`: 等待用户
